# Simple Blog (Next.js)

A minimal blog built with Next.js App Router + Markdown posts.

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Add a post

Create a new `.md` file in `posts/`:

```md
---
title: "My Post"
date: "2026-08-03"
excerpt: "Short summary"
---

Post content here.
```

## Build for production

```bash
npm run build
npm start
```
