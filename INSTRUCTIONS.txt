HOW TO APPLY THIS ZIP
======================
Extract directly into the ROOT of your project (the folder containing
your app/, components/, and lib/ folders) — paths mirror your project
structure exactly, so every file overwrites its existing counterpart at
the same path.

WHAT'S IN THIS UPDATE
-----------------------

1. Onboarding wizard — intro splash + header removed
   components/onboarding/OnboardingWizard.tsx
     - Removed the "GET STARTED" intro splash screen (showIntro/.ob-intro)
       entirely. The wizard now opens straight to Step 1.
     - Removed the header bar (siterifty.com logo + Logout button) that
       sat above the step content. handleLogout() was also removed since
       nothing calls it anymore.
     - Cleaned up the now-redundant manual touchmove blocker — scroll
       lock (see #2 below) handles this itself now.
   app/styles/onboarding.css
     - Unchanged from last update — .ob-intro* rules are correctly
       absent since the intro screen no longer exists in the component.

2. Scroll lock — now blocks iOS touch/rubber-band scroll too
   lib/useScrollLock.ts
     - useScrollLock(active) previously only set body { overflow: hidden
       }, which stops desktop wheel/keyboard scroll but does NOT stop
       iOS Safari from rubber-band scrolling the page behind a
       fixed-position modal via touch drag. It now also adds a
       reference-counted document-level touchmove blocker, so every
       component that already calls useScrollLock (Rate, Donate, seller
       details/report, PlansModal/Upgrade, ThemeModal via
       ThemeModalProvider, OnboardingWizard, etc.) gets real scroll
       lock on mobile with no per-component changes needed.
     - New opt-in escape hatch: add the `data-scroll-lock-exempt`
       attribute to any element that needs to keep scrolling internally
       while the rest of the page is locked (used below).
   components/onboarding/OnboardingWizard.tsx
     - .ob-content-wrapper marked data-scroll-lock-exempt so step
       content taller than the viewport still scrolls normally.
   components/theme/ThemeModal.tsx
     - .theme-card-scroll marked data-scroll-lock-exempt.
   components/seller/DonateOverlay.tsx
     - #spDonateScroll marked data-scroll-lock-exempt.
   components/seller/SellerDetailsOverlay.tsx
     - #spDetailsBox (the modal's own scrollable box) marked
       data-scroll-lock-exempt.
   components/billing/PlansModal.tsx
     - #srfPlansBody marked data-scroll-lock-exempt.

   RateOverlay.tsx and ThemeModalProvider.tsx needed no changes — they
   already call useScrollLock, so they inherit the iOS fix
   automatically from lib/useScrollLock.ts.
